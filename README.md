# Smart Learn Hub — Offline E-Learning Platform

Smart Learn Hub is a Raspberry Pi-powered offline digital learning platform designed to provide accessible and affordable education in regions with limited or no internet connectivity.

The platform creates a local Wi-Fi hotspot that enables students and teachers to connect using smartphones, laptops, or tablets and access educational resources such as video lectures, notes, quizzes, and performance analytics — completely offline.

Built using Raspberry Pi, Flask, SQLite, HTML, CSS, and JavaScript, Smart Learn Hub functions as a portable self-contained classroom server for rural and connectivity-constrained environments.

---

## Problem Statement

Many rural and semi-urban schools lack stable internet connectivity despite having access to digital infrastructure such as smartboards, computers, and smartphones.

Smart Learn Hub addresses this challenge by creating an offline-first educational ecosystem capable of delivering structured curriculum-based learning resources without requiring internet access.

---

## Key Features

* Offline Wi-Fi based learning system
* Raspberry Pi-powered local server
* Student and teacher dashboards
* Video lectures and PDF notes
* Interactive quiz system with instant feedback
* Local SQLite database storage
* Multi-user classroom support
* Low-cost and portable deployment
* Browser-based access without application installation

---

## System Architecture

The Raspberry Pi functions as:

* Local Web Server
* Wi-Fi Hotspot
* Content Delivery System
* Offline Learning Management Platform

Students connect to the local Wi-Fi network and access the learning portal directly through a browser without requiring installation or internet connectivity.

## Workflow

1. Raspberry Pi boots and broadcasts a local Wi-Fi network
2. Students connect to the hotspot
3. Learning portal opens through browser access
4. Students access notes, videos, and quizzes
5. Teacher dashboard monitors student performance and progress
